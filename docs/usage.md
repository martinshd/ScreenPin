# 使用说明

## 安装预览版

0.1.0 安装包适用于 Apple 芯片（M 系列）Mac，需要 macOS 14 或更高版本，不支持 Intel Mac。

1. 从 [Releases](https://github.com/martinshd/ScreenPin/releases) 下载 `ScreenPin-0.1.0-macOS-arm64.zip`。
2. 解压，将 `ScreenPin.app` 拖到「应用程序」文件夹，然后打开。
3. 本版使用本地开发证书签名，**没有 Developer ID 签名，也未通过 Apple 公证**。如果系统提示开发者无法验证，仅在你确认下载来源可信且愿意试用时，在「系统设置 → 隐私与安全性」中选择「仍要打开」，按系统提示确认。

这是针对这一个应用的打开确认，不需要关闭系统安全保护。如果提示应用损坏、含有恶意软件，或没有「仍要打开」选项，请停止操作并反馈具体提示。可参考 [Apple 的说明](https://support.apple.com/en-us/102445)。

每版提供 `SHA256SUMS.txt` 供核对文件完整性；校验值不等于 Apple 公证或安全审查。

## 第一次打开

ScreenPin 启动后会出现在菜单栏中，没有主窗口，也不会出现在 Dock。点击剪刀图标，可以开始截图、查看使用说明或退出应用。

界面跟随系统语言：中文系统显示中文，其余语言显示英文。下面的菜单名称以中文界面为例。

首次截图需要允许「屏幕录制」权限。按照系统提示操作，或在「系统设置 → 隐私与安全性」中找到相应的屏幕录制权限设置；名称可能因 macOS 版本不同而略有变化。授权后如仍无法截图，请退出并重新打开 ScreenPin。

## 截图与贴屏

按 `Control + Option + X`，屏幕会先定格，再用鼠标拖拽框选。松开鼠标后，截图会在原位置置顶，并自动复制到剪贴板。

框选中按 `Esc` 可以取消。想截取下拉菜单时，先展开菜单，再使用快捷键截图。

不在标注模式时，拖动贴图即可移动。右键菜单可以调整透明度，或开启「点击穿透」。开启穿透后，鼠标会操作下方窗口，无法再直接操作这张贴图；可从菜单栏选择「关闭所有贴图」清除。

## 标注

在贴图获得焦点后使用下列快捷键，也可以右键选择标注工具。

| 操作 | 快捷键 |
| --- | --- |
| 画笔 | `B` |
| 箭头 | `A` |
| 文字 | `T`，然后单击需要输入的位置 |
| 循环换色 | `C`（未在文字输入框中时） |
| 撤销上一笔标注 | `Command + Z` |

文字输入中，按 `Enter` 或点击别处提交，按 `Esc` 取消本次输入。文字会根据贴图剩余宽度自动换行。

完成标注后，点击左上角「✕ 退出标注」即可恢复拖动；也可以按 `Enter`，或再按一次当前工具的快捷键。

`Enter` 根据当前状态逐层确认并保留标注：输入文字时提交文字；标注时退出标注；普通贴图状态下关闭贴图。

`Esc` 表示取消：框选时取消截图；输入文字时取消本次输入；标注时退出并丢弃本轮新增标注；普通贴图状态下关闭贴图。想保留本轮标注时，请使用 `Enter` 或左上角退出按钮。

## 复制、保存与关闭

| 操作 | 方式 |
| --- | --- |
| 复制当前贴图，包含标注 | `Command + C`，或右键 → 复制 |
| 保存 PNG 到桌面，包含标注 | `Command + S`，或右键 → 保存到桌面 |
| 保存 PNG 并复制文件路径文字 | `Shift + Command + S` |
| 关闭当前贴图 | `Command + W`，或右键 → 关闭；普通贴图状态也可按 `Esc` |
| 关闭所有贴图 | 菜单栏 → 关闭所有贴图 |

快捷键需要贴图获得焦点。多张贴图同时存在时，如需粘贴指定的一张，请先对它执行复制。文字编辑中，`Command + C` 等组合键可能由输入框处理；需要复制整张图时，先结束文字输入。

新截图、完成的标注以及显式复制操作会更新系统剪贴板，替换其中原有的内容。关闭贴图不会自动保存文件，也不会主动清空剪贴板；需要保留多张图片时，请分别保存。

`Shift + Command + S` 会把剪贴板替换为保存文件的完整路径文字。需要重新粘贴图片时，请在贴图上按 `Command + C`。之后再次完成标注也会将剪贴板更新为图片。

保存的文件名类似 `ScreenPin_20260905_183426.png`。复制或保存成功后，贴图边框会短暂闪烁。

## 常见问题

**打开后没有窗口？**

这是正常现象，请查看菜单栏的剪刀图标。

**截图快捷键没有反应？**

先确认应用正在运行，再从菜单栏尝试截图。如果菜单栏截图正常，请检查其他应用是否占用了 `Control + Option + X`。当前版本没有快捷键自定义界面。

**授权后还是无法截图？**

确认 ScreenPin 的屏幕录制权限已开启，再退出并重新打开应用。仍有问题时，请反馈系统版本和具体提示。

**贴图无法拖动？**

先退出标注模式。如果开启了点击穿透，可从菜单栏关闭所有贴图后重新截图。

**分享问题时需要提供什么？**

请提供应用版本、macOS 版本、Mac 芯片类型、是否使用外接显示器，以及能够复现问题的操作步骤。截图和日志请先检查并移除敏感信息。
