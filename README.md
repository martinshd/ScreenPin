# ScreenPin

来源于选择困难症，只想在mac上有一个简单的截图工具，简单的功能、简单的操作，保留一些快捷的使用习惯。

ScreenPin 是一款 macOS 截图贴屏工具。框选屏幕区域后，截图会留在原位置并置顶，方便你一边查看，一边继续操作。

适合临时对照参数、参考图片，或给截图加上简单说明后分享。

[下载安装](https://github.com/martinshd/ScreenPin/releases) · [使用说明](docs/usage.md) · [反馈问题](https://github.com/martinshd/ScreenPin/issues)

## 能做什么

- **截图后直接贴屏**：按下快捷键定格屏幕，再拖拽框选，也可以截取已展开的下拉菜单。
- **仅3种标注方式**：画笔、箭头和文字，可以换色、撤销。
- **直接粘贴**：截图自动复制到剪贴板，完成标注后也会更新，切到目标应用即可粘贴。
- **按需保存**：将带标注的截图保存为桌面上的 PNG 文件，或保存文件的同时、文件路径进入剪切板（这样就方便指路给大模型看了）。
- **方便对照**：贴图可以移动、调整透明度，也可以开启点击穿透。

应用常驻菜单栏，没有主窗口和 Dock 图标。界面跟随系统语言：中文系统显示中文，其余语言显示英文。

## 开始使用

首版需要 **Apple 芯片（M 系列）Mac，macOS 14 或更高版本**，暂不提供 Intel 安装包。

**这是未通过 Apple 公证的免费预览版**，首次打开可能出现开发者验证提示。安装前请阅读[安装说明](docs/usage.md#安装预览版)。

1. 从 Releases 下载适合你的安装包，按照该版本说明安装。
2. 打开 ScreenPin，在菜单栏找到剪刀图标。
3. 首次截图时，按照系统提示允许「屏幕录制」权限。
4. 按 `Control + Option + X`，拖拽框选需要的内容。

截图会贴在屏幕上，并自动复制到剪贴板。按 `Command + S` 保存到桌面；在其他应用中按 `Command + V` 粘贴。

需要分享文件位置时，按 `Shift + Command + S` 保存并复制文件路径。此时剪贴板中是路径文字，不是图片。
